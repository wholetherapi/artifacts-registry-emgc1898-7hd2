# Systems Reliability Lab — Artifact Registry

Released artifacts are stored as bundle directories under `bundles/<item-slug>/`.

Each bundle README states its release status and lists the shipped contents. A
bundle is **released** only when its README declares a release and the
implementation files are actually present. Bundles that only contain a status
note, a plan, or placeholder directories are not released.

Links published on the portfolio site must point inside this repository. Legacy
archival mirrors under third-party accounts are not authoritative and must not
be used as artifact links.
