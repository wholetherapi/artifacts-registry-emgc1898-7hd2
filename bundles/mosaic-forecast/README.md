# Mosaic Forecast — artifact bundle

**Release status:** Released (v2.1.0) on 2026-04-22.

Ensemble calibration and backtesting code for continental-scale probabilistic
weather forecasting.

## Contents

- `src/ensemble.py` — ensemble member manager
- `src/calibration.py` — probability calibration routines
- `data/stations.csv` — station list for the backtests
- `experiments/backtest.py` — rolling-origin backtest driver
