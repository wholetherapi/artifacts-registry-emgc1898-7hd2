# Nimbus Ledger — artifact bundle

**Release status:** Released (v1.2.0) on 2026-06-15.

Reproducible benchmark harness for permissionless settlement networks.

## Contents

- `src/ledger.py` — settlement engine and account model
- `src/consensus.py` — quorum adapter used by the benchmark
- `data/fixture_orders.csv` — order fixture used for the reported numbers
- `experiments/run_benchmark.sh` — benchmark driver
