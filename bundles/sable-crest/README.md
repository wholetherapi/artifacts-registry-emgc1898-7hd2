# Sable Crest — artifact bundle

**Release status:** Released (v1.0.3) on 2026-10-18.

Calibration methods for models deployed under distribution shift, with a
domain-shift test suite and reference implementation.

## Contents

- `src/calibrator.py` — shift-aware calibrator
- `src/shift_detector.py` — domain-shift detector
- `data/domains.csv` — domain descriptors for the test suite
- `experiments/shift_suite.py` — evaluation driver
